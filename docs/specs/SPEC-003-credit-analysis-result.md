# SPEC-003 — Resultado del análisis

## Objetivo

Mostrar al usuario el porcentaje de deuda/ingreso calculado junto con su categoría correspondiente.

## Formato esperado

Ejemplo:

```text
Porcentaje de deuda: 35.0%
Categoría: Moderado
```

## Criterios de aceptación

1. El resultado debe incluir el porcentaje calculado.
2. El resultado debe incluir la categoría correspondiente.
3. El porcentaje debe mostrarse con el símbolo `%`.
4. No debe agregar recomendaciones ni interpretaciones adicionales.
